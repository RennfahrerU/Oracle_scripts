# Oracle_scripts

Repositorio de scripts SQL y PL/SQL desarrollados para el curso universitario de Oracle. Incluye ejemplos prácticos, talleres y automatizaciones para la administración y consulta de bases de datos Oracle 23ai.

## Descripción

Este proyecto contiene una colección de scripts organizados por temas y talleres, abarcando desde la creación de usuarios y tablespaces, hasta consultas avanzadas y ejercicios prácticos con el esquema [HR](https://github.com/oracle-samples/db-sample-schemas) de Oracle.

## Estructura del repositorio

```
.
├── 2 User Creation and Script Automation/
├── 3 Giving access to HR/
├── 4 Database creation for AirBNB/
├── 5 Introductory SQL Workshop/
├── 6 Taller de SQL Básico/
├── 7 Hacker Rank II/
├── 8 Workshop SQL Windows/
├── 9 Workshop SQL Advanced/
├── 12 Oracle APEX & ORDS/
├── Examples/
├── LICENSE
├── README.md
└── SQL_JOIN_EXAMPLES.jpeg
```

- **2 User Creation and Script Automation/**: Scripts para creación y validación de usuarios.
- **3 Giving access to HR/**: Ejemplos de otorgamiento de permisos y sinónimos sobre el esquema HR.
- **4 Database creation for AirBNB/**: Scripts para modelado y creación de una base de datos tipo AirBNB.
- **5 Introductory SQL Workshop/**: Ejercicios introductorios de SQL.
- **6 Taller de SQL Básico/**: Talleres y ejercicios básicos de SQL en español.
- **7 Hacker Rank II/**: Ejercicios prácticos tipo HackerRank.
- **8 Workshop SQL Windows/**: Ejercicios sobre funciones de ventana.
- **9 Workshop SQL Advanced/**: Consultas avanzadas y ejercicios complejos.
- **12 Oracle APEX & ORDS/**: Scripts para pruebas con Oracle APEX y ORDS.
- **Examples/**: Ejemplos adicionales de consultas SQL.

## Requisitos

- Oracle Database 23ai (o compatible)
- [HR schema](https://github.com/oracle-samples/db-sample-schemas) instalado
- Oracle SQL Developer o cualquier cliente SQL compatible

## Uso

1. Clona este repositorio:
   ```sh
   git clone https://github.com/tu_usuario/Oracle_scripts.git
   ```
2. Abre los scripts en Oracle SQL Developer.
3. Ejecuta los scripts según el taller o ejercicio que desees practicar.
4. Consulta los comentarios en cada archivo para instrucciones específicas.
